# Prince Games

3D Texas Hold'em poker. Join tables, invite friends, win big.

- **Join a Table** – Home → Join a Table Now → first available table → Sit at Table (login if needed)
- **Create Table** – Lobby → Create Table (requires login, auto-seats you)
- **Shared link** – `/join/[code]` or `/table/[id]` (viewable anonymously)

See `docs/REQUIREMENTS.md` for full requirements.
